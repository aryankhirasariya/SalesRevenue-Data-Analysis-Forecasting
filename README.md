# 💹 Sales & Revenue Analytics Dashboard

An interactive data analysis and forecasting dashboard that visualizes historical sales trends and predicts future revenue, built with **Python**, **Pandas**, **Plotly**, and **Streamlit**.

## 🔍 Overview

Understanding sales trends, top-performing products, and regional performance is critical for data-driven business decisions. This project analyzes historical retail sales data and forecasts future revenue using a **Linear Regression** model on monthly aggregated sales.

The dashboard is built with **Streamlit** and lets users upload their own sales CSV to instantly generate KPIs, interactive visualizations, and a revenue forecast for the upcoming months.

## ✨ Features

- 📊 Key metrics at a glance — Total Sales, Total Orders, Average Order Value, Top Region
- 📈 Monthly sales trend line chart
- 🏷️ Sales breakdown by product category (donut chart)
- 🌎 Sales breakdown by region (bar chart)
- 🏆 Top 10 best-selling products
- 🔮 Revenue forecast for the next 1–12 months using Linear Regression
- 📂 CSV upload support — works with any similarly structured sales dataset
- 🌙 Clean, dark-themed, card-based UI

## 🛠️ Tech Stack

- **Python** – core programming language
- **Pandas / NumPy** – data cleaning, aggregation, and time-series preparation
- **Plotly** – interactive charts and visualizations
- **Scikit-learn** – Linear Regression model for forecasting
- **Streamlit** – interactive web dashboard

## 📦 Dataset

**Source:** [Superstore Sales Dataset – Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

The dataset contains retail order-level data including order dates, sales values, product categories, regions, and product names — ideal for trend analysis and time-series forecasting.

**Required columns for the app to work correctly:**
| Column | Description |
|---|---|
| `Order Date` | Date the order was placed |
| `Sales` | Revenue generated by the order |
| `Category` | Product category |
| `Region` | Sales region |
| `Product Name` | Name of the product |
| `Order ID` *(optional)* | Used to calculate total order count |

## ⚙️ Installation

1. **Clone or download this repository**

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Download the dataset**
   Download the CSV from [Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) — no need to place it in the project folder, it's uploaded directly through the app.

## 🚀 Usage

1. **Run the app**
   ```bash
   streamlit run app.py
   ```

2. Open the local URL shown in the terminal (usually `http://localhost:8501`)

3. In the sidebar, click **"Upload your Sales CSV"** and select the Superstore dataset (or any sales CSV with matching column names)

4. Explore the dashboard:
   - View KPI metrics at the top
   - Analyze monthly sales trends
   - Review category and regional breakdowns
   - Check top-performing products
   - Adjust the forecast slider to predict sales for the next 1–12 months

## 🧠 Forecasting Method

- **Approach:** Sales are aggregated monthly, then a **Linear Regression** model is fit on the month index to predict future revenue.
- **Why Linear Regression:** Simple, fast, and interpretable — ideal for demonstrating the forecasting concept.
- **Limitation:** Linear Regression doesn't capture seasonality. For production-grade forecasting, models like **ARIMA**, **SARIMA**, or **Facebook Prophet** would better handle seasonal patterns and trend shifts.

## 🌐 Deployment (Streamlit Community Cloud)

1. Push `app.py` and `requirements.txt` to a GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo and deploy
4. On the live app, upload the Superstore CSV via the sidebar file uploader
